# Product Formula

> Step-by-step framework from idea to launch.

## Phase 1: Validate (1-3 days)

### Find the Niche
- What professional service costs $500+ that AI can replicate?
- What task takes hours that could take seconds?
- What existing tool is overpriced or overcomplicated?

### Validate Demand
- Search volume (Google Trends, Ahrefs)
- Existing competitors making money (good sign)
- Reddit/Twitter complaints about current solutions

### Define the MVP
- One input → one output
- Maximum 3 screens
- Can describe in one sentence

## Phase 2: Build (1-2 weeks)

### Technical Approach
- Use existing AI APIs (not training custom models)
- Simple web app (no mobile apps at launch)
- Serverless where possible

### Core Loop
1. User uploads/inputs something
2. AI processes it
3. User gets result
4. User pays (before or after)

### Launch Checklist
- [ ] Landing page with clear value prop
- [ ] Payment integration (Stripe)
- [ ] Core AI workflow functional
- [ ] Basic error handling
- [ ] Analytics (Plausible/Simple Analytics)

## Phase 3: Launch (1 day)

### Channels
- Twitter/X (product hunt style launch)
- Relevant subreddits
- Hacker News (if technical)
- Niche communities

### Launch Template
```
🚀 Launching [Product Name]

[One sentence: what it does]

[Screenshot/GIF]

Built in [X days] with [tech].

[Link]
```

## Phase 4: Iterate (Ongoing)

### Week 1
- Fix critical bugs
- Respond to every user
- Ship 1-2 improvements based on feedback

### Month 1
- Add most-requested features
- Refine pricing (usually raise it)
- Start content/SEO

### Ongoing
- Automate support patterns
- A/B test pricing
- Consider adjacent products
