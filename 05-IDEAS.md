# 05 - Ideas: How Candidates Are Judged

**Owner:** Anthony (decides what gets built)
**Related files:** [02-THESIS.md](./02-THESIS.md) | [06-PIPELINE.md](./06-PIPELINE.md)
**Last updated:** 2026-08-08

Ideas are not cataloged in this repo. Ideation and pressure-testing happen in the
Idea Lab (a claude.ai project); an idea that survives and is locked for building
gets its own repo on the build system. This repo holds only the model: how ideas
are judged, built, launched, and priced. Keeping candidate ideas out of these pages
is deliberate, so no new evaluation is anchored by an old list.

---

## How Ideas Are Judged

In the Idea Lab, against the standard in [02-THESIS.md](./02-THESIS.md). Every verdict
is one of three: build, kill, or conditional ("build only if X is true, plus the
cheapest way to test X"). There is no numeric score.

## Status Legend

| Status | Meaning |
|---|---|
| 💡 Concept | Captured. Needs validation. |
| 🔍 Researching | Active market/tech research. |
| ✅ Validated | Demand confirmed (interviews, presales, signups). Ready to build. |
| 🚧 Building | In development. See [06-PIPELINE.md](./06-PIPELINE.md). |
| 🚀 Launched | Live. Charging. |
| ⏸️ Paused | On hold. |
| ❌ Killed | Decided not to pursue. Reason logged. |

Statuses live with each product (its own repo once locked), never in this file.
