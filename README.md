# Indie Product Portfolio

> Building niche-specific AI products the indie way — simple, profitable, sustainable.

This repository documents our strategy, thesis, and product pipeline for creating a portfolio of indie AI products under VonDoom Studios.

## Structure

| Folder | Description |
|--------|-------------|
| [thesis/](./thesis/) | The guiding formula for all products — our replicable playbook |
| [ideas/](./ideas/) | Catalog of product concepts, prioritized and detailed |

## Philosophy

- **Niche-specific** — Solve one problem well for a defined audience
- **Simple to build** — Ship fast, iterate faster
- **Low maintenance** — Automate operations, minimize overhead
- **Profitable from day one** — Charge money, validate quickly

## Inspiration

Blueprint modeled on [levelsio](https://x.com/levelsio)'s approach:
- Photo AI ($100K/m)
- Remote OK ($44K/m)
- Vibe Jam ($39K/m)
- Interior AI ($35K/m)
- Nomads ($10K/m)
